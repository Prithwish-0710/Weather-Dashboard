# 🌦️ Weather Dashboard

A modern **React-based Weather Dashboard** that allows users to search cities, view real-time weather data, manage favorites, and visualize forecasts with charts.

---

## 🚀 Live Demo

🔗 **Vercel Deployment:**
👉 https://weather-dashboard-one-omega.vercel.app/

---

## 📌 Features

* 🔍 Search weather by city
* 🌡️ Toggle temperature (°C / °F)
* ⭐ Add / Remove favorite cities
* 📊 Hourly forecast charts
* 🔄 Auto-refresh weather data every 60 seconds
* 💾 Persistent state using Redux
* 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **State Management:** Redux Toolkit
* **Charts:** Chart.js / Recharts (based on your setup)
* **API:** OpenWeatherMap API
* **Routing:** React Router
* **Deployment:** Vercel

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/Prithwish-0710/weather-dashboard.git
cd weather-dashboard
```

---

### 2️⃣ Install dependencies

```
npm install
```

---

👉 Get API key from: https://openweathermap.org/api

---

### 4️⃣ Run the app

```
npm start
```

---

### 5️⃣ Build for production

```
npm run build
```
